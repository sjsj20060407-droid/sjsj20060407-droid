# 你好，我是 Shi Jing

上海财经大学 · 数据科学与大数据技术专业在读。关注零售与消费领域的数据分析：客户分层、销售趋势、评论挖掘。

## 项目

**[online-retail-rfm-analysis](https://github.com/sjsj20060407-droid/online-retail-rfm-analysis)**
基于 Online Retail II 数据集（百万级交易）的 RFM 客户分层，5,878 名客户分为六类并给出运营建议。

**[retail-sales-dashboard](https://github.com/sjsj20060407-droid/retail-sales-dashboard)**
同一数据集的交互式销售看板，Plotly 实现，含 KPI、趋势、排行、时段与客户分析。

**[amazon-reviews-sentiment-analysis](https://github.com/sjsj20060407-droid/amazon-reviews-sentiment-analysis)**
20 万条亚马逊评论的情感分析：VADER 打分与原始标签对比（准确率 71.8%），差评关键词提取。

**[BeautyPulse](https://github.com/sjsj20060407-droid/BeautyPulse)**
小红书与抖音的美妆品牌内容对比分析：互动分布、卖点与痛点提取，附 Streamlit 看板。
